# Company SOP Editor

Edit the company directory under the shared company root: `Instructions/firm.md`, `Instructions/people.md`, `References/`, `policies/POLICY-REGISTER.md`, `LINEAR.md`, `Roles/`, `Playbooks/`, and `Duties/`.

`firm.md` is the short text every turn. Saving a reference adds or updates its line in that file's index. An agent loads a playbook, skill, or reference only when an index line names it.

Saving a file updates its provenance line. A change that needs a permission is a new row in the policy register. The editor does not write a permission header.

The company root is the same setting as Agent Editor. Saving it lays the company pack and seeds the OpenCode config. There is no agent mapping screen.
